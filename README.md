
# Snake Game

## About

This is a simple Snake Game made with Java Swing. In this game, the player controls a snake using the arrow keys. The snake grows when it eats food. The game ends if the snake hits the wall or its own body.

## Features

* Move the snake using arrow keys
* Food appears randomly on the screen
* Snake grows after eating food
* Detects wall collision
* Detects self-collision
* Shows "Game Over" message
* Press R to restart the game

* Interface Implementation

## How to Run

1. Compile all Java files.
2. Run `SnakeGame.java`.
3. Use the arrow keys to play.
4. Press `R` to restart after Game Over.
